# 🤖 Inteligência Documental

## 📌 Visão Geral
Agente especialista em extração e estruturação de documentos financeiros. Esta solução transforma PDFs, imagens e planilhas complexas em dados estruturados (Markdown/JSON) prontos para serem consumidos por sistemas de conciliação e auditoria.

## ⚙️ Como funciona
- [ ] **Entrada:** Documentos desestruturados (NF-e, Extratos, Planos de Contas).
- [ ] **Processamento:** Conversão via `docling`/`markitdown` e filtragem analítica de contas.
- [ ] **Saída:** Arquivos Markdown com tabelas normalizadas e integridade lógica preservada.

## 🛠️ Tecnologias
- Python 3.10+
- Pandas, Openpyxl
- Docling / MarkItDown (Conversão inteligente)
