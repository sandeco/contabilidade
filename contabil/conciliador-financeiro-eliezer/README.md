# 🤖 Conciliador Financeiro

## 📌 Visão Geral
Agente especialista em contabilidade e conciliação bancária. Este agente automatiza a conferência de extratos bancários contra planos de contas e planilhas financeiras utilizando o método de **Partida Dobrada**, garantindo alta precisão e conformidade contábil.

## ⚙️ Como funciona
- [ ] **Entrada:** Extratos Bancários (PDF/OFX), Plano de Contas e Planilha Financeira.
- [ ] **Processamento:** Identificação de contas, classificação de lançamentos e validação em três camadas (Interna, Fiscal e Contábil).
- [ ] **Saída:** Relatório de conciliação estruturado em JSON com status de aprovação e justificativa técnica.

## 🛠️ Tecnologias
- Skill estruturada para LLMs (OpenAI, Gemini, Anthropic).
- Lógica contábil baseada em normas brasileiras e Partida Dobrada.
